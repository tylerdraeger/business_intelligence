## Skills

Skills I used in this course and in my final project ([Retail REITs](https://github.com/tylerdraeger/ISA-Section-A-Final-Project)):

- **R and R Markdown:** cleaning, reshaping, and joining data with dplyr and tidyr
- **Web scraping:** collecting data from web pages with rvest
- **APIs:** pulling data from the SEC, FRED, and Yahoo Finance with httr2, and keeping API keys out of GitHub with .Renviron
- **LLM data extraction:** turning text (earnings press releases) into structured data with ellmer
- **Data validation:** writing rules to catch duplicates, impossible values, and failed joins
- **Tableau:** building charts, dashboards, and a story for presenting results
- **Git and GitHub:** version control and team collaboration
